Using Named Entities

The less-than symbol is written as <. Example: 5 < 10.

The greater-than symbol is written as >. Example: 20 > 15.

The ampersand symbol is written as &. Example: HTML & CSS are used for web development.

Using Hexadecimal Entities

The less-than symbol can also be written as <. Example: 5 < 10.

The greater-than symbol can also be written as >. Example: 20 > 15.

The ampersand symbol can also be written as &. Example: HTML & CSS are used for web development.
